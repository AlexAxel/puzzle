# Puzzle Atelier

Альфа-прототип веб-приложения с фигурной нарезкой изображений в интерактивные пазлы.

**Сайт:** https://alexaxel.github.io/puzzle/

## Контрольная версия

Стабильная версия классического пазла до экспериментов с узорами зафиксирована в ветке [snapshots/classic-stable-2026-10-31](https://github.com/AlexAxel/puzzle/tree/snapshots/classic-stable-2026-10-31) на коммите `477107c4`.

## Текущие возможности

- Загрузка изображений, локальная обработка в браузере
- Настройка размера деталей (54–168 px, максимум 240 деталей)
- Два типа разреза: **Классический** (прежний) и **Узорный** (первый процедурный прототип)
- Самостоятельные детали Canvas, анимация перемешивания, вращение, перетаскивание
- Автоматическая стыковка соседей с объединением в перетаскиваемые группы
- Деревянная игровая доска; GitHub Pages из ветки `main`, папка `docs`

**Узорный** — это пока орнаментальные соединения, не настоящие силуэты птиц и животных. Поддержка SVG-силуэтов запланирована как отдельный следующий этап.

## Авторство и зависимости

`ornate-cut.js` — оригинальная процедурная реализация, написанная для этого проекта. Сторонние алгоритмы нарезки и фигурные SVG-ассеты не копировались. При дальнейшем использовании внешних библиотек/наборов контуров необходимо сохранить их условия лицензирования.
